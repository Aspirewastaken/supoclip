Features Map:
=============

1. COUNTER DISPLAY (Top Center)
   - Shows current position: "X / Total"
   - Fixed positioning with backdrop blur
   - Visible at all times

2. QUICK ACTIONS (Top Right)
   - Heart button (Favorite)
   - X button (Reject)
   - Only shown if handlers provided
   - Floating with shadow

3. NAVIGATION ARROWS (Left/Right)
   - Large circular buttons
   - Left arrow: Previous clip
   - Right arrow: Next clip
   - Auto-hide at boundaries
   - Keyboard shortcut indicators

4. CONTENT AREA (Center)
   - Swipeable container
   - Drag detection (touch + mouse)
   - Animation wrapper
   - Custom content via renderContent()

5. PROGRESS DOTS (Bottom Center)
   - One dot per clip
   - Active dot expands
   - Click to jump to clip
   - Visual feedback

6. SWIPE HINT (Bottom)
   - Shows on first load
   - Fades after 2 seconds
   - Only with multiple clips

Interaction Methods:
====================

1. KEYBOARD
   ┌────────────┬─────────────────────┐
   │ Key        │ Action              │
   ├────────────┼─────────────────────┤
   │ ←          │ Previous clip       │
   │ →          │ Next clip           │
   │ F          │ Favorite (if set)   │
   │ Delete     │ Reject (if set)     │
   └────────────┴─────────────────────┘

2. GESTURES
   ┌────────────┬─────────────────────┐
   │ Gesture    │ Action              │
   ├────────────┼─────────────────────┤
   │ Swipe ←    │ Next clip           │
   │ Swipe →    │ Previous clip       │
   │ Drag ←     │ Next clip           │
   │ Drag →     │ Previous clip       │
   └────────────┴─────────────────────┘

3. CLICKS
   - Click left arrow: Previous
   - Click right arrow: Next
   - Click heart: Favorite
   - Click X: Reject
   - Click dot: Jump to clip

Animation Flow:
===============

Navigation Left (Next):
  Current Clip          New Clip
  [VISIBLE]            [OFF RIGHT]
       ↓                    ↓
  [SLIDE LEFT]        [SLIDE IN FROM RIGHT]
       ↓                    ↓
  [OFF LEFT]          [VISIBLE]

Navigation Right (Previous):
  Current Clip          New Clip
  [VISIBLE]            [OFF LEFT]
       ↓                    ↓
  [SLIDE RIGHT]       [SLIDE IN FROM LEFT]
       ↓                    ↓
  [OFF RIGHT]         [VISIBLE]

Animation Properties:
- Type: Spring physics
- Stiffness: 300
- Damping: 30
- Opacity fade: 0.3s
- Swipe threshold: 50px

Props Interface:
================

export interface SwipeControlsProps {
  // Required
  clips: Clip[];

  id: string;
  url: string;

Event Handlers:
===============

Keyboard Events:
- window.addEventListener("keydown", handleKeyDown)
- Prevents default on arrow keys
- Ignores when focused on inputs

Drag Events:
- onDragStart: Set dragging state
- onDragEnd: Check threshold & navigate
- dragConstraints: Limit drag range
- dragElastic: 0.2 (bounce effect)

Click Events:
- onClick: Arrow buttons
- onClick: Quick action buttons
- onClick: Progress dots

Lifecycle:
- useEffect: Setup keyboard listener
- useEffect cleanup: Remove listener
- useCallback: Memoized handlers
